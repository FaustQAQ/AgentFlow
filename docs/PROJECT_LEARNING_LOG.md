# 项目学习日志

## 2026-11-06：真实销售数据验收

- 旧销售工具测试中的固定金额属于测试契约，不应因此恢复生产模拟数据；正确做法是使用临时 SQLite fixture 与明确标识的测试销售记录。
- `dataset_id` 必须同时存在于执行模型、执行上下文、工具参数和销售查询条件中；只写入用户消息会留下数据串扰风险。
- 同比查询需要查询完整的上一年度对应日期区间；上期无记录时保留 `None`，由确定性指标工具拒绝计算，而不是让 LLM 猜测。
- 浏览器联调发现 `localhost` 与 `127.0.0.1` 的 CORS/端口差异，最终通过显式 `VITE_API_BASE_URL` 与本地 CORS 白名单解决。
- 真实 DeepSeek 调用验证了模型可以多轮选择工具，但关键金额仍由 Python 工具计算，报告只渲染工具结果。
